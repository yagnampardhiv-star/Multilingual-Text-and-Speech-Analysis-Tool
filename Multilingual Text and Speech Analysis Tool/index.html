ABOUT THE PROJECT

Making Language Easy to Understand.

Multilingual Text and Speech Analysis Tool is a web-based application designed to process textual and spoken content. The system provides useful insights such as language selection, sentiment, keywords and basic content statistics.

The project combines HTML, CSS and JavaScript with browser speech recognition technology to create an interactive language analysis platform.
